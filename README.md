# FirePost для DLE 21.0

FirePost · адаптивный шаблон для блога, тематического журнала или новостного сайта на DataLife Engine. В шаблоне есть светлая и тёмная темы, карточки публикаций с обложками и боковая навигация.

[Скачать FirePost 1.0.1 (ZIP)](https://github.com/The88788/FirePost-DLE21/releases/download/v1.0.1/FirePost-DLE21-v1.0.1.zip) · [Все релизы](https://github.com/The88788/FirePost-DLE21/releases) · [Описание и скриншоты](https://the88788.com/files/dle/templates/dle21/138-firepost-dle-21.html)

## Возможности

- Адаптивная вёрстка для компьютера, планшета и телефона.
- Переключение темы в шапке. Сохранённый выбор применяется до загрузки CSS. При первом посещении используется тема системы.
- Поиск, сортировка публикаций, популярные материалы и последние комментарии.
- Меню входа, профиль, закладки, личные сообщения и комментарии с рейтингом.

## Установка

Проверенная конфигурация включает DLE 21.0, PHP 8.3 и jQuery 4. Для установки потребуется своя копия DataLife Engine.

1. Скачайте ZIP из релиза и распакуйте его.
2. Скопируйте папку `FirePost` в каталог `templates` вашей установки DLE.
3. Выберите FirePost в настройках сайта и очистите кеш DLE.
4. Для обложек используйте дополнительное поле `poster` типа «Загружаемое изображение». Если поля нет, создайте его и разрешите использование в нужных категориях.

Подробная инструкция находится в файле `INSTALL.md` внутри ZIP.

Для обновления с 1.0.0 замените `main.tpl` и `js/firepost.js` в папке `FirePost` и очистите кеш DLE. Если вы редактировали эти файлы, перенесите изменения вручную.
